# sneakers-gateway 🐹

> 🧭 Sneakers gateway: GraphQL and machine API for the web, mobile and MCP clients

## 📦 Install

```bash
go get github.com/Sneakers-PAM/sneakers-gateway
```

## 🛠 Develop

```bash
task build    # go build ./...
task test     # go test ./...
task lint     # gofmt check + golangci-lint + yamllint
task license  # check Apache-2.0 headers (golic)
```
